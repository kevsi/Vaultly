Fonctionnalités

Pensé comme un launcher, pas comme un gestionnaire

Tu poses, tu ranges, tu retrouves. Pas de formulaire interminable, pas d'arborescence à apprivoiser.

🗂️

Tuiles & dossiers

Glisse une carte sur une autre pour créer un dossier, dans l'interstice pour la placer. Imbrique, dissous, tout reste simple.

⌨️

Palette instantanée

Ctrl+Alt+Espace où que tu sois : cherche et ouvre n'importe quoi en deux frappes.

📝

Notes post-it

Notes riches colorées (titres, listes, liens), posées directement dans la grille.

📷

Captures automatiques

Aperçu d'écran de chaque site, sans ouvrir le navigateur.

🔗

Liens morts & suivi

Détection des 404, statuts « à traiter / archivé », rappel « à revisiter ».

☁️

Sauvegarde cloud

Backup automatique de ta bibliothèque vers ton cloud (Koofr, Nextcloud, NAS… via WebDAV), restaurable en un clic.

🧩

Extension navigateur

Ajoute la page courante à ta bibliothèque en un clic, depuis Chrome, Brave ou Edge — avec un token dédié limité à l'ajout.

📥

Import favoris

Récupère tes favoris Chrome, Edge, Brave et Firefox en quelques secondes — ou un export HTML/CSV (Pocket, Raindrop…).

🎨

Toi, en grand

Thèmes d'ambiance (dont un esprit manga), polices, style des boutons et fond perso : l'interface se règle à ton goût.

🔔

Rappels

« Me rappeler dans 3 jours » sur une ressource : un toast te la remet sous les yeux au bon moment.

Assistant IA

Ta bibliothèque devient un outil pour ton IA

Vaultly embarque un serveur MCP local : ton assistant (ZCode, Claude, …) peut chercher, ajouter, organiser — et même lancer tes applications Windows. Tout reste sur 127.0.0.1, protégé par des tokens dédiés (accès complet pour l'IA, ajout seul pour l'extension).

💬

« Ajoute le logiciel Chrome »

Tu parles, ton assistant range. Il utilise les 12 outils MCP : recherche, ajout, mise à jour, dossiers, liens morts, lancement d'apps, statistiques…

// config de ton assistant (token dans Réglages → MCP)
{
  "mcpServers": {
    "vaultly": {
      "type": "http",
      "url": "http://127.0.0.1:8765/mcp",
      "headers": {
        "Authorization": "Bearer TON_TOKEN"
      }
    }
  }
}
