Features

Built like a launcher, not another filing system

Drop, organize, find. No endless forms, no folder tree to master.

🗂️

Tiles & folders

Drag one card onto another to create a folder, or drop it between cards to place it. Nest, dissolve, keep everything simple.

⌨️

Instant palette

Ctrl+Alt+Space anywhere on Windows: search and open anything in two keystrokes.

📝

Post-it notes

Rich colored notes with titles, lists and links, placed directly in your grid.

📷

Automatic previews

Get a visual preview of each site without opening the browser.

🔗

Dead links & tracking

Detect 404s, mark resources as “to handle” or “archived”, and get revisit reminders.

☁️

Cloud backup

Back up your library to your own cloud — Koofr, Nextcloud, NAS… via WebDAV — with one-click restore.

🎵

Music & playlists

Play any video link as a track, create playlists, use Play All, and keep control from the mini-bar or floating pill.

🧩

Browser extension

Add the current page to your library with one click from Chrome, Brave or Edge — with a separate add-only token. Download ZIP: unzip it, then load it unpacked in your browser.

📥

Bookmark import

Import Chrome, Edge, Brave and Firefox bookmarks in seconds — or use HTML/CSV exports from Pocket, Raindrop…

🎨

Make it yours

Ambience themes, fonts, button styles and a custom background: tune the interface to your taste.

🔔

Reminders

“Remind me in 3 days” on a resource: Vaultly brings it back to you at the right moment.

AI assistant

Your library becomes an AI tool

Vaultly includes a local MCP server. Your assistant (ZCode, Claude, …) can search, add, organize — and even launch your Windows apps. Everything stays on 127.0.0.1, protected by dedicated tokens: full access for AI, add-only for the browser extension.

💬

“Add the Chrome app”

You speak, your assistant organizes. It uses 12 MCP tools: search, add, update, folders, dead links, app launching, stats…

// Your assistant config (token in Settings → MCP)
{
  "mcpServers": {
    "vaultly": {
      "type": "http",
      "url": "http://127.0.0.1:8765/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}
